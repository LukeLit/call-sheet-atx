# Call Sheet ATX

Find the grants and programs that already exist — and get through them. **Muse** is the assistant.

Public and legal name: **Call Sheet ATX**. Assistant: **Muse**. Texas nonprofit in formation. First city: Austin. The product is built to travel.

Founder: Luke Litman.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
pnpm build
pnpm start
```

## Production host

Temporary production: [csa.ironreach.xyz](https://csa.ironreach.xyz)

Point a real domain later via Porkbun CNAME to this host (or to Vercel once deployed).

## Stack

Next.js 14.2 (App Router) · React 18 · TypeScript 5.6 · Tailwind 3.4 · Framer Motion 11 · pnpm
