# Open Call

Artists shouldn't have to be grant researchers to make a living from their work. **Muse** is the assistant.

Public and legal name: **Open Call**. Assistant: **Muse**. Texas nonprofit in formation. First city: Austin. The product is built to travel.

Founder: Luke Litman.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
pnpm build
pnpm start
```

## Production host

Temporary production: [csa.ironreach.xyz](https://csa.ironreach.xyz)

Point a real domain later via Porkbun CNAME to this host (or to Vercel once deployed).

## Stack
